Warum das nicht warten sollte

Der Pixel im Laden gehört zum gesperrten KatzenUfo-Konto. Dein Werbekonto darf ihn nicht einmal lesen. Solange das so bleibt, läuft jeder Besucher durch, ohne gezählt zu werden — und die Anzeigen können nur auf Klicks optimieren statt auf Warenkorb oder Kauf.

Drei Wege führen ans Ziel

Zwei können dich aussperren, einer nicht

Shopify-Kanal → Datenfreigabe unsicher

Der neue Pixel taucht dort nur auf, wenn der Kanal am richtigen Facebook-Konto hängt. Kann sein, muss nicht.

Meta → Partner-Integration unsicher

Führt auf business.facebook.com — genau die Ecke, die dich mit der alten Telefonnummer schon einmal ausgesperrt hat.

Kundenereignis in Shopify funktioniert immer

Kein Facebook-Login, kein Business Manager, keine Verbindung zwischen den beiden Diensten. Nur Code im Laden, der an die Pixelnummer meldet.

Sechs Schritte, etwa zwei Minuten

So setzt du es ein

  1. Shopify öffnen, Einstellungen → Kundenereignisse Direkt dorthin →
  2. Oben rechts auf Benutzerdefiniertes Pixel hinzufügen
  3. Als Namen Meta Pixel Let'sDrink eintragen
  4. Beim Kundenschutz zweimal umstellen: Berechtigung auf erforderlich, Beschränkung auf Marketing. Damit feuert der Pixel nur mit Zustimmung. Das ist nicht Vorsicht um der Vorsicht willen — ein Marketing-Pixel ohne Zustimmung ist genau das, was das Datenschutzgesetz meint.
  5. Den Code unten in das grosse Feld einfügen
  6. Speichern, dann Verbinden — und einmal deine Startseite aufrufen. Sag mir danach Bescheid. Ich sehe in derselben Abfrage nach, die bisher „null" gemeldet hat.

Ehrlich gerechnet

Was dieser Weg kann — und was nicht

Kann — fünf Ereignisse mit Betrag

Seitenaufruf, Produktansicht, Warenkorb, Kassenstart und Kauf, jeweils mit Betrag und Währung. Das ist mehr, als der Shopify-Kanal im Browser meldet: dort feuert „Produkt angesehen" nur auf Produktseiten und lässt die Startseite aus. Genau diese Messlücke hat die 1,3 Prozent erzeugt, die ich fälschlich für ein Verkaufsproblem gehalten habe.

Kann nicht — die Conversions API

Das ist der zweite, serverseitige Kanal, der auch meldet, wenn ein Browser blockt. Den gibt es nur über die Partner-Integration. Für den Anfang reicht der Browserkanal: er genügt, damit eine Kampagne auf Warenkorb oder Kauf lernen kann.

Doppelte Zählung? Nein. Der Shopify-Kanal meldet an 1978393872804216, dieser Code an 883186891300328. Zwei verschiedene Pixel, keine Überschneidung.

Falls die Partner-Integration bei Meta später doch klappt, muss dieser Code wieder heraus — sonst zählt derselbe Kauf zweimal.
